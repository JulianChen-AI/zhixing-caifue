# 竞品实操流程详查 · 微众银行 App vs 中国银行 App

> **用途**：对着《知行语音银行》六大场景的每个子任务，逐一还原两家银行 App 的真实操作流程，作为答辩"痛点真实、空白真实"的竞品实拍级证据。
> **资料口径**：
> - 微众银行转账部分 = 2026-10-25 本团队 App 实拍截图 20 张（一手证据，存于 `智能转账流程图片/`）；
> - 微众银行其余部分 = 公开报道与官方公告整理，页路径以 App 实际展示为准（已标注"待验证"处请勿直接引用数字）；
> - 中国银行 = 中行官网服务页/业务协议/FAQ + 公开答主经验贴，新旧口径并存处均已并列标注；
> - 两家银行都没有能力的子任务按规则跳过；仅一方有的如实写明另一方"无此能力"。
> **安全提示**：所有流程仅用于产品研究，不要在这些页面里真实发起转账或交易。

# 场景一 · 智能转账

## 1.1 按人名转账

### 微众银行：无"按人名直达"，最近路径是"历史转账收款人 + 银行卡号表单"

微众的收款人识别是**卡号驱动**的：表单核心是"收款人姓名 + 收款卡号"两项，人名只是校验字段，不存在"说人名就定位账户"的能力。

A. 前置门槛（向他人转账开关，实拍确认）
1. 账户首页 → 微众卡 →「转出」→ 转出主页（银行卡号转账 / 手机号转账 / 定时转账 / 转给本人 / 转给他人 / 信用卡还款六个入口）。
2. 首次点「银行卡号转账」或「转给他人」，弹窗拦截："您需要先手动开启向他人及非绑定卡转账的功能" → 选「去开启」。
3. 进入人脸验证：协议页（取景框/避免遮挡/光线适宜三提示）→「同意协议并开始验证」→ 录制并上传视频审核。
4. 审核通过后进入「转出限额」页：「转给他人（含本人非绑定卡）」开关默认关闭，手动打开；开启后**单日限额 1 万元、年度限额 20 万元**，限额含消费/缴费、向非绑定账户转出和取出现金（Ⅱ类户口径）。「转给本人（绑定卡）」默认单笔 1 亿 / 单日 10 亿 / 年度 100 亿 / 单日 1000 次。

B. 发起转账（实拍确认）
1. 转出主页 →「银行卡号转账」→「转账到银行卡」表单：
   - 收款人：输入对方真实姓名，支持「添加生僻字」，右侧有通讯录图标可从本机通讯录选人（仅带入姓名，不带入账户）；
   - 收款卡号：手输或点相机图标拍照识别。
2. 卡号输完后 App 自动识别银行与卡种（实测显示"中国银行 储蓄卡 银联"标识）→「下一步」。
3. 转出金额页：输入金额（显示"联动支付当前可转出金额 X 元"）→「转账备注」字段（收款方可见，选填）→「实时转出（当日无收益）」默认勾选，展示可实时转出金额与预计到账时间 → 确认。
4. 安全认证（密码/人脸，具体强度按金额）→ 成功页 + 交易记录。

C. 离"按人名"最近的功能：「转给他人（历史转账收款人）」
- 从转出主页进入「转给他人」，列表展示历史转账收款人（头像 + 姓名 + 尾号），点选后免重复输卡号直接进入金额页。
- 局限：只覆盖"转过账的人"；没有通讯录解析、没有重名消歧、没有收款人逐字回读，陌生人仍然要手输"姓名 + 完整卡号"两项。

### 中国银行：同样无"按人名直达"，靠"收款人管理"复用历史收款人

A. 常用收款人维护
- 入口：手机银行「转账汇款」→「收款人管理」（网银为"收款人信息"）；常用收款人最多保存 120 个，手机银行与网银共享。
- 新增方式：转账成功后勾选"保存收款人"；或在收款人管理中手动新增（收款人姓名、账号、开户行）。
- 可设"默认收款账户"（个人设定功能），方便后续收款操作。

B. 按名点选发起转账
1. 登录中国银行 App → 首页「转账」（置顶四大功能键之一）→「转账汇款」。
2. 选转账类型：关联账户转账 / 中行内转账汇款 / 国内跨行转账汇款。
3. 收款人一栏从"常用收款人"列表点选（或重新手输姓名 + 账号 + 开户行）；跨行需选收款银行。
4. 填金额、选付款账户、填用途/附言 → 选择安全认证方式（手机交易码 / 人脸识别 / 手机盾 / 中银 e 盾，按页面提供）→ 确认提交。
5. 银行不校验收款账户真实性：收款账号/户名错误造成退款的，手续费不退（中行风险提示原文口径）。

C. 速查对比
| 环节 | 微众银行 | 中国银行 |
|---|---|---|
| 人名定位账户 | 仅历史收款人列表点选 | 常用收款人（120 个）点选 |
| 陌生人首次转账 | 手输姓名+卡号，卡号自动识别银行 | 手输姓名+账号+开户行 |
| 前置门槛 | 人脸验证开启"向他人转账"开关（单日1万/年20万） | 无开关；限额按账户类别与认证工具 |
| 回读确认 | 无逐字回读，表单自核 | 无逐字回读，表单自核 |

## 1.2 按手机号转账

### 微众银行（实拍确认）：前提是"对方手机号已关联银行卡"，且要手选收款银行

A. 付款方发起流程
1. 转出主页 →「手机号转账」→ 引导页"输入手机号即可转账，一键转账到手机号关联的银行卡"（附「查看详情」「我的手机号转账关联卡」）→「下一步」。
2. 收款表单三项必填：**收款人（对方真实姓名）、手机号、收款银行（需手动选择银行）**——并非输手机号就能走。
3. 点下一步校验：若该手机号**未关联任何银行卡**，弹窗"该手机号暂未关联银行卡，请输入银行卡号进行转账"，只能取消或转走「银行卡号转账」——流程在此断裂，无降级通道。
4. 校验通过后进入金额页（同 1.1.B.3）→ 安全认证 → 完成。

B. 收款方（本人）关联流程
1. 「手机号转账」引导页 →「我的手机号转账关联卡」→「关联微众卡」。
2. 页面自动带出本人姓名（掩码"林\*\*"）和手机号（掩码"130\*\*\*\*2714"）→ 获取并输入**短信验证码**（60 秒重发）。
3. 勾选可选框"将手机号对应的默认卡更新为微众卡"→「下一步」。
4. **人脸验证**（同 1.1.A.3 流程）→ 审核通过后生效。

C. 关键事实（答辩可直接引用）
- 无户名掩码回显核验：付款方输完手机号，App 不显示"该号码登记人：X\*X"供核对——转错号码没有任何拦截点；
- 收款银行要付款人**手选**（中行也有类似要求，见下）；
- 对方没绑卡 = 硬性断点，只能退回卡号转账。

### 中国银行：人行"手机号码支付/超级网银 IBPS"的中行场景（详见团队范例文档，此处摘要）

A. 收款方开通/绑定流程
- 前提：本人中行个人人民币结算账户（不含信用卡）；手机号须为开户签约预留手机号；同一手机号在中行只能关联一个本人账户。
- 入口：App 首页「转账」→「手机号转账」，或搜索"手机号转账/手机号转账设置"；也可走"转账汇款—手机号转账—设置/签约设置"。
- 从绑定账户中选借记卡、普通活期或活期一本通作为默认收款账户；确认户名、账号、手机号，勾选同意《中国银行手机号转账协议》，完成安全认证后生效。
- 人行"四个一"规则：一个银行账户只关联一个手机号；一个手机号可关联多家银行账户但在一家银行只能关联一个账户；一个手机号只能被一个客户注册；一个客户可注册多个手机号。部分资料要求预留手机号满 6 个月、绑定账户有实际交易，以开户行核验为准。
- 变更预留手机号、注销关联账户、换绑账号或姓名/证件变更，中行会主动向人行跨行清算系统提交注销，需重新注册。

B. 付款方发起流程
1. 登录 App →「转账/转账汇款」→「手机号转账」。
2. 调起通讯录或手输收款人姓名 + 手机号；若页面展示脱敏账号/姓名尾号，务必二次核对。
3. 输入金额、选付款账户、用途/备注；**收款方必须已设定默认收款账户才能收款**（中行 FAQ 明确）。
4. 按页面选安全认证方式（手机盾、手机交易码+人脸识别、手机交易码+手机盾、中银 e 盾等，以交易页为准）。
5. 提交后依托超级网银处理：公开口径实时到账、7×24；早期地方报道"单笔最多 5 万元"，后续科普称支持额度提升，单笔/日累计以 App 实时提示为准。
6. 可按收款人手机号和汇款用途发短信通知收款人；预约转账在执行日通知。

C. 风险提示（中行原文口径）：银行不判断收款账户真实性，账号/户名错误造成退款的手续费不退；不要只凭聊天窗口里的手机号直接转。

## 1.3 备注转账

### 微众银行（实拍确认）
- 备注只是"转出金额页"的一个字段：「转账备注——收款方可见（选填）」，旁边仅提供「添加生僻字」。
- 全程纯手输文本：无模板、无语义识别、无分类标签、不与任何对账/账单功能联动。

### 中国银行
- 转账汇款表单内含"用途/附言"字段：国内跨行转账一般需从用途下拉项中选择（如工资、货款、赡养费等监管要求的大类），另附"附言"自由文本（字数有限制，以页面为准）；用途/附言随交易报送并展示给收款方。
- 同样无任何智能备注能力。

## 1.4 定时转账

### 微众银行（实拍确认）：叫"定时转账"，预设日期自动转账

A. 设置流程
1. 转出主页 →「定时转账」→ 引导页"预设日期 · 自动转账"（三卖点：轻松预约/定时转账/省心管理）→「添加定时转账」；右上角「+」管理已建计划。
2. 先选**到账日期**：底部滚轮选择月 / 日（实测可选 10 月 25 日、11 月 26 日、12 月 27 日……）。
3. 填写表单：**金额、收款人（请填写收款人…，支持添加生僻字）、收款卡号、付款方式（先扣微众卡再扣活期+，ⓘ有说明）**。
4. 确认后生成定时任务（截图未展示执行前提醒与失败处置文案）。

B. 与范例对照的关键缺口
- 是"选日期 + 填表单"的预约模式，截图未见"每月 X 号"式周期规则、扣款前余额校验提醒、失败是否重试的说明；
- 未见撤销/管理界面的实拍（「+」入口推测为管理页，待验证）。

### 中国银行：叫"预约转账"，分"预约日期"和"预约周期"（详见团队范例文档，此处摘要）

A. 设置流程
1. 入口：手机银行【转账汇款】-【预约转账】；网银在【转账汇款】-【中行内/跨行转账汇款】后按提示发起。
2. 选转账类型：关联账户转账、中行内转账、国内跨行转账；能否直接预约"手机号转账"以 App 预约页是否提供入口为准。
3. 填要素：币种、金额、转出账户、转入账户/收款人、备注；常用收款人最多 120 个。
4. 选执行方式：立即执行 / 预约日期（未来 3 个月内任意一天）/ 预约周期（起始日未来 1 个月内、结束日未来 6 个月内；周期单周/双周/月）。
5. 核对 + 安全认证（网银支持 CA 证书；手机银行支持手机盾/人脸组合等，以页面为准）→ 生成指令；5 万元以上大额跨行非工作时间提交会提示"预约在下一个工作日自动汇划"。

B. 执行与到账：中行内转账公开口径 0:00 起执行；跨行 ≤5 万 0:00 起、>5 万大额 9:00 起；大额跨行原则上工作日 9:00—17:00 受理，非交易时间自动转交下一工作日。

C. 查询/撤销：手机银行【转账】-【预约转账】-【预约查询及撤销】；可按执行日期或预约日期查询；可删除未执行指令（删周期指令会删该周期内全部未执行指令）；已执行指令不可删除；公开材料未明确余额不足是否自动重试——执行日前保持余额充足，失败拨 95566。

## 1.5 拆分 AA 收款

两家银行 App 均无 AA/拆单收款功能（该能力由微信/支付宝群收款提供）→ **按规则跳过**。

# 场景二 · 理财操作

## 2.1 产品推荐与对比

### 微众银行：货架式陈列 + 场景专区，"对比"靠详情页要素自行比对

A. 产品货架
- 入口：App 底部「理财」「基金」频道（实拍首页底栏：账户/理财/基金/权益/我的）。
- 产品线分层（公开报道口径）：活期+（0.01 元起购、7×24 申赎、支持微信支付等消费场景直接扣款）；活期+Plus（7 天以上、持有满 7 天可随时转出、500 万以内实时到账）；固收+（按风险分低波/中波/高波三类）；公募基金（宽基、行业、债券、QDII）；存款与结构性产品。

B. 特色专区："定投纳指"（公开报道口径）
1. 底部「基金」→ 专区图标进入 → 展示多只纳指基金（报道口径最高一键勾选 33 只）及**当日可用限额（实时变动）**、近一年涨跌幅。
2. 一键全选或自定义勾选 → 设金额与频率（每日/每月）→ 确认后从活期+扣款。
3. 差异化能力：系统自动分配并买满当日可用 QDII 额度；"省心智能定投"可监控额度变化、放开后自动加仓。
4. 对比呈现：同屏展示多基金涨跌幅与限额，但**无多产品要素并列对比工具**——费率、持仓、回撤等需逐个进入详情页自行比对。

C. 费用与权益：588 积分兑换基金申购费 0 折权益（有效期一年）；部分活动期 0 折卡（报道口径，以 App 为准）。

### 中国银行：基金超市 + 风险等级匹配过滤，无并列对比工具

A. 产品货架
- 入口：手机银行「财富/理财」频道 → 基金 / 理财 / 代销资管 / 结构性存款分类；可按类型、风险等级、业绩筛选。
- 产品风险等级 R1—R5 展示于详情页（要素、净值走势、费率、销售文件）。

B. 购买前的匹配过滤（关键差异点）
- 客户风险评级（C1 谨慎—C5 激进）低于产品风险等级时，**原则上不得购买**；C2 及以上普通投资者买公募基金可申请超配，但需确认"已知晓风险并愿意自担不利结果"，银行以电子文档做特别警示，确认后方可购买（《代销类资产管理产品销售协议》口径）。
- 每只产品详情页有"风险揭示书"需阅读确认。

C. 对比呈现：同货架多产品列表字段对比（净值、涨跌幅、风险等级），无"双产品并排对比"工具。

## 2.2 风险识别（风险承受能力评估）

### 微众银行：全线上，首次购买前按页面指引完成

A. 流程（公开报道 + 实拍旁证）
1. 线上开户（身份核验 + 绑卡）→ 首次进入理财/基金购买流程时，页面引导完成**投资者风险测评**，全程在线，无线下环节。
2. 测评结果决定可购买产品范围；结果页面展示风险等级。
3. 测评有效期与重测触发：以 App 提示为准（公开资料未披露统一年限，**待验证**，勿引用具体数字）。

### 中国银行：C1—C5 五级，有效期 1 年，多渠道可办

A. 规则（官网协议/权益须知口径）
- 首次购买公募基金、代销理财和信托计划等前，必须填写《个人客户风险测评问卷》；风险评估结果有效期 **12 个月**，超期或财务状况发生重大变化需重新评估（网点、网银、手机银行均可办理）。
- 评级 C1 谨慎型—C5 激进型；产品 R1—R5；评级低于产品等级原则上不可购买；超配购买需特别警示 + 投资者确认。
- 评调整类告知：产品风险等级上调时银行及时告知，投资者需自行决策。

B. 流程
1. 手机银行「财富」→ 首次购买任意理财/基金 → 弹窗引导测评 → 在线答题（收入、资产、投资经验、期限偏好等）→ 提交出结果。
2. 也可主动在"我的/安全中心"或购买页重新测评；到期后再购买会强制重新测评。

## 2.3 一键申购 / 赎回

### 微众银行：路径短、余额扣款、快赎是卖点

A. 申购/定投（公开报道口径）
1. 「基金」频道 → 选产品 → 详情页「申购/定投」→ 输入金额（定投设金额 + 频率）→ 确认 → 从活期+或账户余额扣款，无需跳转。
2. 定投扣款默认从活期+扣；**余额不足则当次定投失败**，不会自动解冻定期存款、不罚违约金，补足后下一扣款日自动恢复（界面新闻实测报道口径）。
3. 申购费 0 折权益（积分兑换）在确认页抵扣展示。

B. 赎回
- 持仓页 → 选基金 →「赎回」→ 份额与到账方式确认 → 提交。
- 到账时效：常规赎回到账按基金类型 T+1~T+N；**快赎 T+0.5**（银行垫资，受总额度限制，非法定义务）；定投纳指专区基金快赎 T+1.5（投资家网评测口径）。
- 撤单：以 App 交易页为准（待验证，未找到公开口径）。

### 中国银行：交易时间、挂单、撤单、定投失败规则最完整

A. 交易规则（官网口径）
- 交易时间：每周一至周五 9:00—15:00（认购截止 16:00）；非交易时间委托视为下一日交易，非交易时间如产品开通挂单则挂单下一交易日执行。
- 撤单：认购、申购（不含定投）与赎回在**当日交易截止时间前可撤单，且均为全额撤单**。
- 指定日期交易：中行网银支持 T+1 日到 T+90 日的指定日期基金申购/赎回（FAQ 口径）。
- 巨额赎回：可选择顺延（未成交部分延迟下一交易日）或非顺延。

B. 申购流程
1. 手机银行「财富」→ 基金 → 选产品 → 风险匹配校验（超配需特别警示确认）→ 阅读风险揭示书 → 输金额、选资金账户 → 安全认证 → 委托受理。
2. T+2 日及之后查询确认结果（以产品管理人确认为准）。

C. 定投流程
1. 基金详情页 →「定投」→ 约定每期扣款日期与金额、选扣款账户 → 确认生效。
2. 扣款日账户状态不正常或余额不足 = 当次失败；**连续三次扣款失败，定投申请自动取消**。
3. 定赎（定期定额赎回）：每月一次，约定赎回日期与份额，当日份额不足判失败。
4. 修改/终止：变更扣款金额与日期、终止定投可在基金持仓/定投管理办理（网银/手机银行均可）。

D. 赎回流程
1. 基金持仓 → 选基金 →「赎回」→ 全部或部分份额 → 确认费率与预计到账 → 认证提交。
2. 封闭期/最短持有期产品持有期内不可赎回（销售文件为准）。

# 场景三 · 账单分析

## 3.1 消费分类统计

### 微众银行：只有流水，没有分类
- 首页「交易记录」入口（实拍确认）：按时间罗列收支流水，无商户清洗、无消费分类、无类目统计图表。
- 无第三方账单导入、无记账能力。

- 入口：手机银行「账户管理」→「收支记录/收支分析」（中国经济网 2020 年评测口径：App 上线收支记录/收支分析等金融助手）。
- 能力：对本行账户流水做收支汇总与图表分析；**暂不支持交易流水导出**（同评测口径）。
- 局限：仅本行账户口径——年轻人真实消费大头在微信/支付宝，银行侧看不到；无年轻人专属分类体系（盲盒/剧本杀/打赏无类可归）、无语音查账、无纠错学习。

## 3.2 异常交易识别

### 两家均无语义级异常识别，只有"动账通知"级提醒
- 微众银行：交易发生时推送动账通知（微信/短信/App），无"连续小额盗刷""订阅悄悄扣费"等模式识别。
- 中国银行：「中银 e 信」定制短信提醒服务（可按金额阈值/渠道定制动账提醒）；信用卡侧有盗刷电话止付通道（40066-95566 或 8610-66085566 否认交易申请）。
- 结论：均为"逐笔通知"，无"从流水里发现不像你"的聚合研判——子任务层面的智能识别两家都没有，保留本节以留证。

## 3.3 月度 / 年度账单分析

### 微众银行
- 无月度账单/年度账单产品；「交易记录」可按月筛选查看，仅此而已。

### 中国银行
- 月度账单：手机银行支持「月度账单」查询（手机银行基本知识 FAQ 口径：可查"余额、交易明细、收支记录、月度账单"）。
- 年度账单：2020 年版起 App 新增"年度账单"产品（中国经济网评测口径）——年度消费回顾类页面；无同龄分位参照、无洞察到行动的衔接。
- 速查对比：中行有"账单回顾"形态但无语义洞察；微众连形态都没有。

# 场景四 · 卡片管理

## 4.1 卡申请

### 微众银行：电子账户开户即"有卡"，无实体卡/信用卡申请场景
- 微众卡是电子账户（Ⅱ类户为主），注册开户 + 身份核验 + 绑卡后账户即刻可用，App 内展示卡号（可绑微信/支付宝），**无"选卡种、申卡审批"的货架流程**。
- 微众银行不发行信用卡，无信用卡申请入口。
- 结论：赛题"卡申请"子任务在微众侧只对应"开户"，无决策导航空间。

### 中国银行：借记卡"网点申请为主、主题卡可线上预约"；信用卡全线上申请

A. 借记卡申请
1. 常规：本人持有效身份证件到网点填写申请表 → 当场领卡（Ⅰ类户受一人一行一户限制）。
2. 主题卡线上预约（以 B 站联名借记卡为例，中行官网 2026 年 9 月页面口径）：登录手机银行 → B 站专区线上预约 → 提交预约 → 约 7—15 个工作日制卡并邮寄至指定领卡网点 → 携身份证到网点领卡开户。
3. 费用：按《中国银行服务价目表》收工本费/年费，各主题卡优惠以页面为准。

B. 信用卡申请
1. 入口：手机银行「信用卡」频道 →「在线申卡」；或"中国银行信用卡"微信公众号、"缤纷生活"App。
2. 选卡种 → 填申请资料（身份、职业、收入、联系人等）→ 提交 → 银行审核（征信查询需授权）→ 寄卡 → 激活。
3. 进度查询：手机银行信用卡频道「办卡进度」。

## 4.2 额度调整

### 微众银行（实拍确认）：只有"限额"没有"授信额度"
- 「转出限额」页（路径：转出主页右上角限额图标）：
  - 「转给他人（含本人非绑定卡）」开关 + **单日限额 1 万 / 年度限额 20 万**（含消费/缴费、向非绑定账户转出和取现，Ⅱ类户口径；账户非柜面转账单日超 30 万会有大额交易提醒——微众官网公告口径）；
  - 「转给本人（绑定卡）」：单笔 1 亿 / 单日 10 亿 / 年度 100 亿 / 单日 1000 次（默认展示值，可申请提升额度入口在页内）；
  - 扣款顺序说明：转账时先扣微众卡、后扣活期+、再扣活期+Plus；联动实时转出活期+/Plus 受其实时转出额度约束。

### 中国银行：信用卡额度（临时/长期）+ 借记卡交易限额，两套体系

A. 信用卡额度调整（官网口径，新旧口径并存）
1. 临时额度：手机银行、"中国银行信用卡"微信公众号、「缤纷生活」App、网银、客服热线 40066-95566 均可申请；**仅主卡可申请**，附属卡额度由主卡设定；临时增额会查征信。
2. 有效期：官网不同页面存在"最长 30 天"与"最长 60 天"两种口径，**以 App 申请页实时展示为准**；到期自动恢复原额度，临额内透支须在到期还款日前还清，否则超限计息。
3. 长期额度：提额由银行根据消费/透支/还款记录**定期或不定期主动调升**；持卡人长期降额可致电客服办理；部分口径要求持卡满 6 个月方可申请长期调额。

B. 借记卡交易限额设置
1. 入口 A：手机银行「账户管理」→ 选卡 →「限额设置」（POS 消费日限额、ATM 无卡取款等逐项设置，输新限额 + 密码确认）。
2. 入口 B：「更多」→「支付管理」→「跨行支付」→「在线支付」：开通银联跨行无卡支付并**按卡设每日累计限额**（默认每卡每日 5 万元，可调高/调低/关闭）。
3. Ⅰ类户境内 POS 消费本身无限额（不设即无上限），境外 POS 消费限额产品层默认：普通卡每日等值 100 万元、中银理财贵宾 300 万、财富管理贵宾 500 万；调整可携身份证到联网网点。
4. 单笔限额由银行规定不可自设；客户自设的是"每日累计限额"维度。

## 4.3 交易限制解锁

### 微众银行：人脸 + 开关体系，无公开的"风控误伤申诉"通道
- 实拍可见的控制点：向他人转账开关（人脸开启）、转出限额页各项限额、限额说明及到账说明。
- 账户被风控限制时：App 内无公开的"限制原因查询/申诉"入口（未见于截图与公开资料），一般走客服 95384 人工核实——**"误伤救援"体验空白，待验证**。

### 中国银行：锁定/冻结有明确的自助与柜台分级路径（官网 FAQ 口径）
A. 手机银行/网银登录锁定
- 当日连续 5 次登录失败：临时冻结，**次日零点自动解冻**；急需可当日携身份证 + 任一关联卡/折到网点解冻。
- 用户名密码累计 15 次校验未通过（动态口令累计 10/15 次错误）：正式锁定，**必须本人携证件到网点解锁，不可代办**。
- 中银 e 盾（USBKey）密码连错 5 次：CA 证书锁定，须网点补发证书（填《个人综合服务信息变更申请表》→ 打印参考号授权码 → USBKey 初始化 → 重新下载证书）。

B. 账户级限制
- 借记卡密码遗忘：手机银行可自助密码重置（未开通手机银行的先 95566 临时挂失，再网点办理）。
- 账户冻结/止付：网银"银行账户"菜单提供「借记卡临时挂失」「账户冻结止付」自助操作；解冻按提示或网点办理。
- 交易被反欺诈系统拦截：无公开的自助复核入口，按页面提示或 95566 人工处理。

## 4.4 卡片挂失

### 微众银行：电子账户，无实体卡挂失；对应能力是"账户冻结 + 设备管理"
- 微众卡无实体介质，丢失场景主要是"手机丢失/账户异常"：App「我的」→「设置」→ 账户安全相关入口（登录密码修改、支付管理、设备管理）+ 致电 95384 紧急冻结账户（公开资料未见自助挂失菜单，**路径待验证**）。
- 无补卡、无绑定关系迁移概念。

### 中国银行：临时挂失（5 日/长期）→ 正式挂失 → 补卡，链条完整

A. 借记卡挂失（官网口径）
1. 临时挂失：手机银行自助办理，或拨 95566；属"介质挂失"，分 **5 日**与**长期**两档——5 日档须在 5 日内到网点办正式手续，第 6 日自动失效；长期档可随时到网点正式挂失或撤销。
2. 正式挂失：本人持有效身份证件到**任一联网网点**办理（不可代办）；挂失费/工本费按当日《服务价目表》。
3. 补卡：正式挂失后在**发卡省份（直辖市）内**联网网点补换卡；部分卡种支持保号换卡（需约 2 周后再次到网点领卡，以上海师大财务处口径为例）；新卡激活后旧卡作废。
4. 临时挂失期间资金：介质挂失不冻结账户（以网点口径为准）。

B. 信用卡挂失（官网口径）
1. 手机银行挂失 = **正式挂失**（不是临时挂失）：「信用卡」→「信用卡功能设定」→「信用卡挂失/补卡」→ 选卡 → 挂失类型选"挂失及补卡"→ 选认证工具 → 确认挂失/补卡信息（邮寄方式与地址）→ 安全认证 → 提交成功；挂失费按信用卡价目表。
2. 电话挂失：致电 40066-95566 即为正式挂失，无需书面确认；挂失手续生效后的卡片损失由银行承担。
3. 卡未丢但被盗刷：致电 8610-66085566/66085569 止付 + 否认交易申请；小额免密免签可通过 App/微信/客服关闭。

C. 关键差异对照
| 环节 | 微众银行 | 中国银行 |
|---|---|---|
| 挂失形态 | 无实体卡，账户级冻结 | 介质挂失（5日/长期）+ 正式挂失 |
| 自助程度 | 待验证（客服为主） | 临时挂失全自助；正式挂失需网点 |
| 补卡 | 不涉及 | 省内网点，部分保号 |
| 绑定关系迁移 | 无概念 | 无工具（自行回忆换绑） |

# 场景五 · 订阅代扣管理

## 5.1 自动识别订阅扣费
- 微众银行：**无**订阅/代扣协议识别能力。
- 中国银行：**无自动识别**，但有协议级查询入口（见 5.3 的签约关系查询）——只能"自己记得去查"，不能"帮你发现"。

## 5.2 续费提醒
两家银行均无"续费前 T-5 提醒、试用到期预警、涨价检测"能力 → **按规则跳过**。

## 5.3 一键取消订阅（银行侧实际对应能力 = 协议支付/快捷支付解约）

### 微众银行：无公开的代扣协议管理入口
- 公开资料与实拍均未发现"代扣协议/快捷支付管理"菜单；微众卡绑定微信/支付宝后的解约需到微信/支付宝侧操作。**无此能力（待验证，以 App 搜索"协议/代扣"为准）**。

### 中国银行：协议支付/快捷支付可查询、可解约，但只管"银行侧授权"

A. 协议查询
- 网银：「电子支付」→「协议支付」→「签约关系查询」，可查已签协议信息、修改日累计限额（≤银行上限）、查一年内协议支付记录（单次查询跨度 ≤3 个月）。
- 手机银行：账户总览选签约卡 →「支付设置」→「无感支付」查看签约关系（公开答主口径）；或「支付管理」→「快捷支付管理」。
- 已知限额口径：协议支付单笔最高 1000 元、日累计最高 5000 元（部分商户更低）。

B. 解约流程
1. 网银路径：签约关系查询 → 选中协议号 →「解约」→ 输入动态口令/CA 证书确认。
2. 手机银行路径：「支付设置」→「无感支付」→ 选签约关系 →「解约」。
3. 商户侧路径：在支付宝/微信等平台解绑中行卡，快捷支付即关闭；银行侧协议与商户侧协议可能不同步（CSDN 行业分析口径：银行侧解约后商户系统未必实时感知，可能出现"商户显示仍开通但扣款失败"）。
4. 线下兜底：携身份证 + 银行卡到网点，可查询并注销全部第三方协议（含水电煤等纸质代扣协议必须到网点）。

C. 关键边界（与赛题方案的对应点）
- 银行解除的是**该通道的付款授权**，不等于商户退订、不等于退款；商户换通道扣款银行管不了——中行没有任何"结果核验/下周期观察"闭环。

# 场景六：跨场景联动（事件驱动 / 自动计划 / 跨 App 编排）

## 6.1 工资到账 → 自动理财（发薪日自动转入理财）

### 微众银行：管家式自动计划（"微众银行财富+"平台化能力）
公开评测（凤凰科技、网易）口径，**以 App 内"自动计划/工资理财"入口为准**：

1. 入口：App「财富+」或账户页 →「自动计划」（或搜索"工资理财"）。
2. 新建计划：选择触发条件——"每月 X 日发薪后"或"余额超过 N 元时"。
3. 设定动作：自动将指定金额/超出部分转入活期+（或指定理财产品/基金定投）。
4. 确认生效：显示下次执行日期；可在计划列表随时暂停/修改/终止。
5. 执行记录：每笔自动转入在活期+明细中可见，失败（余额不足等）会推送提醒。

关键边界：
- 本质是"按日期的定时任务"，**不是真正感知工资到账事件**（跨行发薪流水无法被触发式识别，只能按约定日期执行）。

### 中国银行：基金定投 ≈ 定时计划，无"发薪联动"
1. 手机银行 →「财富」或「基金」→ 选产品 →「定投」。
2. 设置扣款周期（每周/双周/每月 X 日）、扣款金额、扣款账户。
3. 确认协议（定投协议），生效后自动扣款申购；**连续 3 次扣款失败自动取消定投**。
4. 修改/终止：定投管理列表 → 选计划 → 暂停/终止。

关键边界：纯日历触发，与发薪无关联；工资到账后手动"余额理财/活钱管理"购买。

## 6.2 自动还房贷/信用卡

### 微众银行
- 微众无信用卡业务、无房贷业务 → 无自动还款场景。

### 中国银行
A. 信用卡自动还款
1. 手机银行 →「信用卡」→「自动还款设置」（或卡片管理 → 还款管理）。
2. 绑定/选择本行借记卡作为还款账户。
3. 选择扣款方式：**全额还款**或**最低还款额**。
4. 确认后生效：到期还款日按约定自动扣款；可随时修改或关闭。

B. 房贷自动还款
1. 贷款发放时在网点/网银签订委托扣款协议，绑定还款账户。
2. 每月约定扣款日自动从借记卡扣款；需保证扣款日 17:00 前账户余额充足。
3. 手机银行 →「贷款」→ 可查询还款计划、手动提前还款；**扣款协议变更须网点办理**。

## 6.3 事件驱动主动规划（账单日发提醒、大额入账后建议存定期、余额不足预警）

- 微众银行：有"活期+余额不足自动转入/余额自动理财"类开关（管家式自动计划的变体），以及大额资金到账后的理财产品推荐弹窗，但**均为规则化/推荐式，无跨事件编排**。
- 中国银行：有大额动账短信/推送提醒、贷款还款日前提醒，**无"事件 → 理财建议"的主动规划**。
- 两家均无跨 App 编排能力（如"支付宝账单日 → 银行侧调额/备款"），赛题如做此方向无直接竞品对标。

## 6.4 定时公益/其他定时任务
- 微众银行：管家式自动计划中支持"定时转账"类任务（即场景一的定时转账），公开评测提及"定时公益捐款"类自动计划，**以 App 为准**。
- 中国银行：无定时公益；周期类只有预约转账（按周/月重复）与基金定投。
