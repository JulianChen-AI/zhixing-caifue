# 第一部分 · 我们要做什么（TL;DR）

**一句话**：在知行语音银行 Agent 里内置一只理财伙伴企鹅「财富鹅」——用户的财务状况长成这只企鹅的样子；用户通过与它对话完成理财操作（产品信息查询与对比、风险识别、一键申购/赎回），企鹅随用户财务健康共同成长。

**目标人群**（v1.4 扩展）：年满 18 周岁的在校大学生（大一至研二）+ 初入职场新人（毕业 0-3 年），约 18-27 岁——从帮你攒下第一笔 3000 块，到帮你管好第一笔工资（完整画像见 3.1）。

**四大功能支柱**（覆盖售前→售中→售后全旅程）：
1. **目标储蓄（目标罐）** —— 一句话创建有名字、有进度、有仪式感的储蓄目标（毕业旅行小金库、考研小金库），可改可停
2. **理财启蒙剧本** —— 对话式剧本杀，5-8 轮对话学会一个理财知识点（投教工具，非合规测评），取代产品说明书
3. **理财成长等级** —— 投资者适当性管理的 Agent 化：**业务开通只看"标准风险测评画像 + 对应认知课程"**，成长等级只是界面呈现；测评到期重测
4. **售后陪伴闭环** —— 持仓总览、收益播报盯盘、画像偏离事实提示、赎回完整链、交易对账：买完之后陪伴才刚开始

**两条安全机制**：
- **冲动提醒 · 冷静档案** —— 检测异常申购信号，触发陪伴式提醒与强确认 + 历史冲动复盘（软拦截，不延迟成交、不妨碍交易自主权）
- **成长只绑行为质量、绝不绑金额** —— 游戏化成长值不诱导多买；**业务开通门槛属合规适当性范畴，与成长值是两套体系**（见 5.2 注）

**评审点命中**：任务完成率 40%（多步规划任务链）+ 安全合规 30%（适当性管理完整流程展示 + 风险揭示留痕）+ 创新性 30%（对话式剧本投教 + 反消费主义叙事 + 情感化交互），一段演示打多个得分项。

> **内部视角背书（v1.7，董小峰会议）**：理财操作被明确为六大场景中**"想象空间最大、最推荐聚焦"**的场景——售前售中售后、复盘、底层资产解读、产品对比都有文章可做；本报告四大功能支柱恰好覆盖这一全旅程。**交互参考**：牛牛 AI（市面成熟金融 AI）会展示思考过程——检索财报、持仓、新闻、讨论区情绪后再给结论；财富鹅的产品解读/对比可借鉴此"分析透明化"设计（检索了什么→依据是什么→结论），同时天然契合纲领四"讲清依据和不确定性"。
>
> **行为设计学锚点（v1.8，理论层见《行为设计学理论层》）**：本场景是**过度自信**的主场——①理财启蒙剧本=**校准训练**（calibration）：不说"你不懂理财"，让用户在沙盒剧本里自己选错一次，过度自信安全泄压；②目标罐/预算锁定=**承诺机制**（Ulysses contract）：让清醒自信的自己约束未来冲动的自己，Save More Tomorrow 的本土化；③"推荐/调仓降级为客观信息"（D3/F13）=**不用"你懂理财"的自信诱导交易**——这是黑暗模式与助推的分水岭。**有限注意力**侧：替用户读完产品说明书并翻译成人话（注意力外包）；冲动提醒只在注意力窗口（大额异常信号当下）出现一次。**信贷禁区**：双概念绝不用于任何借贷诱导。

# 第三部分 · 需求依据：为什么年轻人需要这个

## 3.1 目标人群与完整人物画像（v1.4 扩展：大学生 + 职场新人）

### 3.1.1 人群定义：从"被供养"到"自食其力"的完整过渡期

**目标人群 = 年满 18 周岁的在校大学生（大一至研二）+ 初入职场新人（毕业 0-3 年），约 18-27 岁。**

> **年龄门槛（v1.5 补，D2）**：理财/基金开户要求年满 18 周岁且具备完全民事行为能力。产品交易功能仅向 18+ 用户开放；未满 18 岁用户仅可使用投教内容（剧本、企鹅陪伴），不开放申购、定投等任何交易功能。大一新生未满 18 岁者按此规则处理。

扩展理由有三：

1. **微众官方叙事就是全生命周期**：刘舒老师原话——"大一把他变成微众忠实用户，大四毕业工资转过来，继续买微众的产品。"毕业不是用户旅程的终点，而是**转化点**；只做在校段等于在收获前夜离场。
2. **理财需求真正起量是在入职后**：在校期月均可支配结余通常只有几百元，理财场景偏"启蒙与习惯"；入职后月薪数千、第一次有了可投资资产，"产品对比、申购赎回、持仓盯盘"才从演示场景变成真实刚需。两个段落拼起来，财富鹅"陪你一起成长"的主线才完整——**从帮你攒下第一笔 3000 块，到帮你管好第一笔工资**。
3. **合规空间的澄清**：大学生专项监管（银保监办发〔2021〕28 号）约束的是**在校段**；职场新人段按一般金融消费者保护执行，运营空间更大。两段人群的合规口径不同，设计时已区分（见第七部分 R4 适用范围）。

### 3.1.2 四阶段分层（故事线与功能优先级依据）

| 阶段 | 资金特征 | 核心金融任务 | 代表性时刻 | 财富鹅的角色 |
|---|---|---|---|---|
| 大一–大二（须满 18 岁方可交易） | 纯生活费，月 1500 上下，来源全靠家里 | 生活费分配、先存后花、防骗、小额目标储蓄 | 月初发生活费、社团 AA、双十一 | 陪练：养成"先存后花"习惯 |
| 大三–大四 | 生活费 + 兼职/实习收入，开始有结余 | 兼职工资管理、毕业旅行攒钱、求职期防招聘诈骗、就业过渡储备 | 第一份实习工资、毕业季 | 启蒙老师：投教剧本、第一笔定投 |
| 研一–研二 | 奖助学金 + 助研津贴 + 实习 | 小额理财启蒙、定投纪律、为离校储备 | 奖学金到账、offer 落定 | 规划伙伴：目标储蓄体系化 |
| **职场新人（0-3 年）** | 月薪数千、发薪日周期、房租/五险一金/通勤等固定支出、第一次有"大钱" | 工资分配（房租/生活/储蓄三分法）、发薪日自动划转、应急金建立、基金定投进阶、年终奖规划 | 第一笔正式工资、第一次交房租押金、第一次年终奖、跳槽空窗期 | 财务分身：全旅程功能全开，盯盘/对账高频使用 |

### 3.1.3 三个具象人物画像（Persona）

**Persona 1 · 小知｜20 岁，大二女生，文科**
- **资金结构**：月生活费 1600 元，全部来自家里，月初一次性到账；无兼职；娱乐社交支出占比最高
- **金融行为**：支付全走微信/支付宝，银行卡是沉睡账户；唯一"理财"是余额宝里常年躺着的 300 块
- **痛点**：月初大手大脚月底吃土；想攒钱但没盼头、坚持不下来；记账 App 下了三个都弃了；直播间冲动消费后懊悔
- **与财富鹅的一天**：生活费到账 → 企鹅提醒"先存后花"，自动锁 150 进"演唱会小金库"；深夜逛直播间想买 399 的盲盒 → 企鹅触发冲动提醒，调出她上月的冲动档案；周末收到企鹅日记："主人这周忍住两次冲动，给我攒了 2 根小鱼干"
- **最常用功能**：目标储蓄、冲动提醒与冷静档案、企鹅日记

**Persona 2 · 阿澈｜22 岁，大四男生，工科，实习中**
- **资金结构**：生活费 1500 + 实习日薪 150（月入约 2000-3000 波动）；毕业季支出集中（租房押金、置装、毕业旅行）
- **金融行为**：有 5000 元存款躺在活期；刷到过"大学生稳赚理财"短视频，心动又不敢；求职季收到过"培训贷"式骚扰
- **痛点**：毕业用钱的地方扎堆却没有规划；怕亏更怕被骗；听说过定投但不知道从何开始；不好意思问人（社恐式金融）
- **与财富鹅的一天**：实习工资到账 → 按预设规则 30% 自动锁定"毕业过渡小金库"；说"剩的钱想试试理财" → 企鹅先带他过投教剧本《大熊市漂流记》，再完成正式风险测评（对话式标准问卷）评出 R2"稳重鹅"，开通债基定投每周 50；收到可疑"高薪兼职"链接 → 剧本 2《骗子来了》的桥段他真遇上了，直接问企鹅核实
- **最常用功能**：启蒙剧本、风险测评、小额定投、防骗联动

**Persona 3 · 栗子｜24 岁，女，入职 8 个月，互联网公司运营**
- **资金结构**：月薪 7500 元（**税后到手**；v1.8 统一口径——对齐账单场景 3-B2 修订：7500 为税后到手个体设定，账单 3.2 表 7850 为本科起薪**税前均值**，两者口径不同不矛盾），每月 10 号发薪；房租 1800 + 水电通勤约 2500 固定支出；花呗账单约 1200/月；工作以来攒下 1.2 万，全在活期
- **金融行为**：工资卡就是微众账户（校招时被推荐开的）；知道该理财但"下班只想躺平，没精力研究"；买过一只网红基金被套 8%，从此不敢再看
- **痛点**：工资到账先还花呗，剩多少算多少，"三分法"听过但执行不了；被套经历造成亏损阴影；1.2 万活期躺着贬值有焦虑感；想建立应急金但不知道"多少算够"
- **与财富鹅的一天**：发薪日 → 企鹅按上月一起定的规则自动划转：房租+生活预算留足后，1500 进应急金目标、500 进债基定投；打开 App 问"我赚了还是亏了" → 持仓总览一句话讲清（事实 + 风险提示双轨），被套那只基金企鹅陪她复盘（当初买入时画像并不匹配，现在认知补上了）；月底企鹅播报："这个月你的储蓄率 28%，超过了自己定的 25% 目标"
- **最常用功能**：发薪日自动划转、持仓总览、盯盘播报、交易对账

# 第五部分 · 产品方案：财富鹅体系

## 5.1 核心定位

**你的财务状况，长成一只企鹅的样子。**
企鹅不是游戏皮肤，是金融行为的"情感化身"——成长状态 = 财务健康的可视化镜像。

血脉叙事：微众由腾讯发起，企鹅是腾讯系金融的天然符号；QQ 宠物回归热点正当时。"微众继承了腾讯最懂年轻人的基因，我们让这只企鹅第一次走进银行。"

## 5.2 三条红线（答辩关键亮点，不可妥协）

| 红线 | 含义 |
|---|---|
| ① 成长只绑"行为质量"，绝不绑"金额" | 成长值来自：坚持定投、完成风险学习、资产分散、冲动提醒应对成功——家境不同，企鹅可以一样健康 |
| ② 企鹅不会"死"或惩罚性退化 | 市场大跌时企鹅"陪你裹紧围巾"，不掉级——避免恐慌割肉时被产品二次伤害 |
| ③ 适当性永远优先于养成目标 | 画像不匹配时企鹅温柔劝阻，绝不帮着下单 |

> **⚠️ 红线①的边界（v1.5 补，B2/F3）**：红线①约束的是**游戏化成长值（XP/等级呈现）**——它绝不绑金额。但**业务开通门槛属于合规适当性范畴**：标准风险测评法定须包含财务状况（收入、资产、可投资金额等，《证券期货投资者适当性管理办法》），两者是**两套体系**，互不替代。文档中任何"成长等级"字样均指界面呈现层，不作业务开通依据（见 5.4 功能 3 映射表）。

**行业里游戏化金融都在想"怎么让用户多买"，我们第一个把"不让用户乱买"做成核心玩法。**

## 5.3 企鹅成长体系（每个维度都有金融语义）

| 企鹅维度 | 金融含义 | 数据来源 |
|---|---|---|
| 成长阶段（蛋→幼鹅→少年鹅→成年鹅→绅士鹅） | 财务健康分：应急金覆盖率、储蓄率、负债健康度、保障完备度 | 账户+行为数据 |
| 体型/气色 | 财务行为规律性（记账/定投连续打卡） | 行为日志 |
| 性格（6 种，呼应新版 QQ 宠物） | 风险画像可视化：保守型="稳重鹅"，进取型="冒险鹅"，随测评画像演化 | 标准风险测评结果 |
| 装扮/小屋 | 成就实体化：风险学习→学士帽、定投 3 月→小金库、应对冲动提醒→冷静勋章 | 成就系统 |
| 心情/天气特效 | 持仓状态+市场环境：晴天=稳健；下雨=波动（企鹅撑伞陪你） | 行情数据 |
| 企鹅日记（AI 生成） | 企鹅视角复盘本周财务行为："主人这周忍住没买球鞋，给我攒了 200 块小鱼干" | 大模型生成 |

## 5.4 四大功能支柱 + 两条安全机制

### 功能 1：目标储蓄（目标罐）⭐主推

> **命名说明（v1.5，F7）**：本功能底层是"子账户 + 自动锁定 + 转入"的**目标储蓄**，不是基金。产品侧统一命名为"目标储蓄 / 目标罐 / 小金库"，**禁用"基金"字样**，避免"储蓄≠基金"的术语误导（货基≠存款同理，见功能 3）。技术内部 ID 保留 goal_fund.* 历史命名。

用户一句话创建："帮我建一个毕业旅行小金库，目标 3000，明年 6 月前存够。"

行为链：
1. **拆解目标**：3000÷8 个月≈每月 375 → "要不要每月生活费到账后自动锁 375？"
2. **自动锁定**：到账触发，按比例转入子账户，可写心情备注
3. **进度播报**：每周/每次转入后一句话反馈 + 企鹅成长可视化
4. **柔性取用**：急用可取出，但企鹅温柔提醒（"取出后旅行小金库要延期 1 个月，确定吗？"）——用对话成本代替锁死
5. **兑现仪式**：目标达成主动祝贺 + 生成可分享的"成长报告"
6. **可改可停（v1.3 补）**：改目标金额、延期、暂停自动锁定都一句话完成（TF-19）；暂停自动锁定即时生效、随时可恢复——"可撤回"是消保办法 R6 的硬要求，必须零阻力

演示金句：*"理财产品都在劝你买，我们的 Agent 先问你为什么存。"*

### 功能 2：理财启蒙剧本（对话式剧本杀 · 投教工具）

触发：用户说"我想学理财"，或账单分析发现结余时企鹅主动邀请。

首批 3 个剧本（每个 5-8 轮对话）：
- 剧本 1《500 元的抉择》：结余分配（储蓄/消费/基金的区别）——**兼作债券基金认知课程**
- 剧本 2《骗子来了》：识别"高收益稳赚"话术（联动安全故事线）
- 剧本 3《定投的威力》：用用户自己的结余数字算账（含分红方式知识点）

通关奖励：经验值 +20。

> **⚠️ 定性（v1.5，D1）**：剧本是**投教工具/演示道具**，不承担合规适当性测评职能。剧情中的行为信号（risk_signal）仅作为**企鹅性格演化与投教推荐的辅助参考**，不写入合规测评结果；正式测评见功能 3。剧本 XP 奖励与测评结果**数据解耦**（R14），防止用户为升级而"演"。

### 功能 3：理财成长等级（适当性管理 Agent 化）⭐安全合规得分点

**三层映射表（v1.5 新增，B9——全文以此为准）**：

| 成长等级（界面呈现层） | 风险画像 R1-R5（合规锚点层） | 可办业务（业务层） |
|---|---|---|
| L1 新手 | 完成**标准风险测评**（对话式呈现，题目来自持牌机构标准问卷，含财务状况题） | 货币基金/零钱通类的讲解与转入（**必须附带"货币基金不等同于存款、不保本"提示**，F8） |
| L2 进阶 | 测评画像 ≥R2 **且**完成《500 元的抉择》债券基金认知课程 | 债券基金定投（50 元起） |
| L3 熟手 | 测评画像 ≥R3 **且**完成进阶认知课程 | 指数基金定投 |

**核心原则：业务开通只看"标准测评画像 + 对应认知课程"，成长等级只是界面提示；金额、游戏关卡进度一律不作业务开通条件（B2/B3/F2/R14）。**

关键设计：
- **等级不够时拒绝并解释**："指数基金波动大，你连亏 10% 会不会睡不着还没测过——先完成进阶课程并通过测评，过了我立刻给你开。"——适当性合规的完整流程展示
- 每次真实操作前：费率明示 + 风险揭示朗读 + 显式确认（"我念一遍费用和风险，你说'确认'我才下单"）——风险揭示留痕 + 电子确认
- 风险测评对话化呈现（题目本身为标准问卷）："如果你存的 1000 块一个月变成 900，你会 A 立刻取出 B 放着不管 C 再加点"
- **重测机制（v1.5 修订，F1）**：监管要求"定期或不定期"重新评估，无统一年限；本方案按机构内部标准设有效期 1 年。到期前 7 天企鹅温柔提醒重测（TF-20），到期未重测则限制新业务（只可赎回/查询，话术解释原因、随时可补测）；行为信号与画像持续冲突时可触发画像漂移重测。重测换新的问卷题序防"背答案"。企鹅性格"随画像演化"由本机制支撑。

### 功能 4：售后陪伴闭环（盯盘 · 播报 · 事实提示）⭐v1.3 补齐的最大缺口

买完之后发生什么，由这一功能回答——它同时是"财富鹅=财务健康可视化"定位的闭环前提（企鹅心情/天气的数据源）：

1. **持仓总览**（TF-14）："我赚了还是亏了"一句话问出全账户答案；收益话术 = 事实 + 风险提示双轨、禁止外推预测（R1 词库）
2. **收益播报与盯盘**（TF-15）：用户订阅（"跌了告诉我"）+ 净值更新 + 异动阈值三触发；播报 = 事实 + 陪伴，不喊操作指令；每日最多 1 条防打扰（R10）
3. **画像偏离事实提示**（TF-15，v1.5 修订 D3/F13）：仅陈述事实——"你的资产分布与你的风险测评结果不一致"，**不含任何"该不该调、调到哪里"的倾向**（资产配置建议属投顾行为，需持牌，见 R13）
4. **赎回完整链**（TF-10 扩展）：到账时间、赎回费、部分赎回全说明；赎回是留痕重点环节，合规上比申购更需要完整流程
5. **交易对账**（TF-17）：成交/扣款/撤单记录一句话可查，audit_logs 数据直接复用

**演示金句**：*"别的理财 App 卖完就结束了，我们的陪伴从买完之后才开始。"*

### 安全机制 A：冲动提醒 · 冷静档案（v1.5 修订：软拦截，F4/R7）

> **定性**：普通公募基金申购**没有法定冷静期**，且客户画像匹配、产品合法时机构**无权拒绝其正当申购**（交易自主权）。因此本机制是**反冲动的话术化提醒与强确认（软拦截）**，不是强制延迟成交。

- 触发信号：硬信号（金额超画像阈值、深夜时段——确定性代码判定）+ 软信号（疑似追涨、情绪化表述——LLM 辅助信号）。**软信号永远不能单独触发流程，只能叠加在硬信号上提升提醒等级**（B6）
- 流程：企鹅提示（不说教）→ 调出冷静档案（历史冲动行为事后复盘）→ 用户三选：① "24 小时后再提醒我"（**用户自设提醒，不锁单、不延迟成交**）② 改为小额试投 ③ 坚持执行（强确认 + 留痕标记"用户已确认坚持"）
- 赎回时区分"需要用钱" vs "恐慌割肉"，后者触发陪伴式复盘（同样不阻碍执行）
- **⚠️ 合规（R7）**：本流程绝不得阻碍用户正当申购/赎回——赎回权与交易自主权不能设障
- **⚠️ 数据合规（R8）**：冷静档案属于负面行为画像数据，复用须在产品协议中单独告知并取得同意，且设数据保留期限上限

### 安全机制 B：能力边界声明

学 Erica：企鹅明确"我给信息，最终决策在你"；**产品推荐与对比只做客观信息陈列**（要素、风险等级、历史表现并标注"历史业绩不代表未来表现"），不做个性化投资建议（D3/F13/R13）；不提供个股推荐、不承诺收益；AI 量化类请求礼貌拒绝（调研报告 9.4 已登记为不采纳，监管敏感）。

### 明确不做（边界声明）
- ❌ 社交圈/帖子/打赏/知识付费　❌ 独立游戏中心/Unity（对话即剧本）
- ❌ 广告变现/商业模式测算　❌ 个性化投资建议/投顾服务（无资质，只做客观信息陈列）
- ❌ 真实资金申购（演示到用户"确认"为止，执行结果以沙箱模拟字幕呈现并声明"真实产品需二次验证"）
- ❌ AI 量化荐股模块

## 6.1 总体架构（五层）

```
┌─────────────────────────────────────────────┐
│  呈现层  对话界面 + 财富鹅可视化（成长/心情/日记）  │
├─────────────────────────────────────────────┤
│  对话层  LLM 编排：意图识别 → 多步规划 → 话术生成   │
│         （System Prompt + 工具调用 + 剧本引擎）     │
├─────────────────────────────────────────────┤
│  护栏层  适当性规则引擎 / 冲动提醒器 / 留痕记录      │  ← 硬护栏为确定性代码，不可被 LLM 绕过
├─────────────────────────────────────────────┤
│  工具层  沙箱银行 API：账户/基金/定投/测评/子账户    │
├─────────────────────────────────────────────┤
│  数据层  用户画像 / 风险档案 / 企鹅状态 / 冷静档案   │
└─────────────────────────────────────────────┘
```

**核心架构原则：护栏层硬软分层（v1.5 修订，B6）。**

| 类型 | 内容 | 实现 | 权限 |
|---|---|---|---|
| **硬护栏** | 年龄 ≥18、金额阈值、时段、画像-产品风险匹配、课程完成状态、费率/风险揭示与确认留痕 | 确定性代码 | 可拦截、可拒绝 |
| **软信号** | 疑似追涨、情绪化表述等语义判断 | LLM 辅助识别 | **永远不能单独拦截**，只能叠加在硬信号上提升提醒/确认等级 |

LLM 只负责"解释护栏的决定"，永远不能自己判断"这次要不要拦截"。技术叙事："我们的合规不靠 prompt，靠架构。"

**前置假设（v1.5 补，F6）**：账户开立、实名认证、KYC、反洗钱尽职调查与可疑交易监测**复用微众银行现有体系**；本模块所有功能以"账户已合规开立"为前提，不重复建设，但答辩须主动声明这一边界，避免被认为遗漏金融基础合规。

## 6.3 关键任务流详设

> **任务链五环节映射（设计纲领·纲领一/二，v1.6 显式化）**：本文所有 TF 流程均按官方任务链五环节组织——**① 意图理解**（用户原话/改口接续）、**② 信息调用**（[工具] 调用与护栏字段注入）、**③ 任务规划**（Step 顺序与分支）、**④ 结果解释**（LLM 人话输出，遵循 6.7 依据句规范）、**⑤ 后续操作**（结尾主动给出下一步选项）。**确认节点**（纲领三）在伪代码中以"用户确认/说'确认'/显式确认"字样显式标注；评审三标准验收口径：改口重规划=上下文、护栏先于执行=顺序合理、人话转译+依据句=结果可理解。

## 6.7 LLM 编排要点

- **System Prompt 结构**：角色（财富鹅人格）→ 能力边界声明（只做客观信息，不做投资建议）→ 可用工具清单 → 护栏话术模板（拒绝/分流/提醒三段式）→ 当前用户状态注入（测评画像、课程完成、企鹅状态、冷静档案摘要）
- **工具调用**：用 function calling；所有护栏相关字段（risk_level、课程完成、年龄）由后端注入工具结果，**不接受模型自报**
- **话术红线**：禁止收益承诺词与拟人化误导词（"稳赚""保本""肯定涨""钱我来盯""保证达成"）——输出层加正则/分类器过滤，双保险
- **依据句规范（设计纲领·纲领四，v1.6 新增）**：**话术三分层**——事实（持仓/净值/费率数据）/ 推断（画像匹配度、偏离提示）/ 建议（行动选项）在输出中可区分；一切提示必带**依据句**（"你的资产分布与你的风险测评结果不一致"——说数据不说定性）；一切估算必标**推测成分**；收益话术事实+风险双轨、禁止外推预测（R1 既有纪律与本规范同源）——不得把可能性包装成确定结论（官方原文红线）
- **错误恢复**：工具返回失败时，企鹅用拟人化话术重试/换路径，不暴露技术错误

## 7.3 红线反向修订过的设计点（务必知悉）

> **收尾**：时间快进半年，应急金达标，企鹅戴上绅士领结："你现在比我刚认识你时，厉害多啦。"

**演示执行边界（口头声明）**：演示到用户"确认"为止，执行结果以沙箱模拟字幕呈现；真实产品需二次验证；全部数字为合成数据。

**一段戏命中的评审点**：意图识别、多步规划（存钱→课程→标准测评→费率与风险揭示→下单五步）、适当性管理（画像+课程门槛、留痕）、冲动提醒（软拦截，用户坚持可执行）、**售后闭环（持仓查询+盯盘播报+赎回说明三件套）**、错误恢复（撤单/改计划随时可插演）、游戏化创新、真实痛点背书（先存后花来自朋友圈调研）。

# 第十部分 · 差异化对照与原创性声明（防抄袭质疑 · 全队统一口径）

> 用途：评委若质疑"这个是不是见过"，全队按本节口径应答。
> 判断框架：**著作权保护"表达"，不保护"思想、玩法、机制"**。目标储蓄、游戏化投教、智能助理、适当性门槛均为行业通用模式（竞品调研已为每个模式找到 3-4 个国内外独立例证）；我们所有美术、文案、代码均为原创。

## 10.1 与成长盈（前年冠军）逐项对照 —— 最深的相似点，最硬的差异表

| 维度 | 成长盈（前年） | 我们（知行 · 财富鹅） | 差异性质 |
|---|---|---|---|
| 载体 | APP 新版本（页面、按钮、Unity 游戏引擎） | 语音/对话 Agent，多轮对话即剧本 | 形态完全不同 |
| 目标储蓄 | 毕业/职场基金：页面式转入、进度条 | 目标储蓄（目标罐）：一句话创建、Agent 拆解目标、自动规则、柔性取用对话 | 模式通用（朋友圈自发提出 + 赛题官方示例 + Jago Pockets/Monzo Pots 国际例证三方互证），实现路径完全不同；且我们明确"储蓄≠基金"命名纪律（F7） |
| 游戏化投教 | 独立游戏中心，通关得金币 | 对话式剧本杀作为**投教工具**，行为信号仅辅助画像演化；正式适当性测评为对话式标准问卷（D1） | 行业空白点，竞品调研确认无人做 |
| 门槛机制 | 金额 + 游戏关卡双门槛解锁产品 | **门槛只锚"标准测评画像 + 认知课程"**，金额/关卡一律不作条件（B2/F2/R14），XP 与测评数据解耦 | 与成长盈结构的根本切割：我们把适当性还给了合规，把游戏化留在了呈现层 |
| 企鹅元素 | 企鹅小助手（陪伴挂件） | 财富鹅 = 财务健康可视化本体（成长/性格/心情均有金融语义），三条红线约束 | 挂件 vs 本体；且我们企鹅形象原创、命名避嫌 |
| 评审语境 | 产品完整度、商业闭环 | 任务完成率 + 安全合规 + 创新交互（40/30/30） | 赛道不同，评分锚点不同 |

**应答话术（被问成长盈时）**：
> "目标储蓄和门槛解锁是投资者适当性管理的通行实现，行业内有大量先例。我们的差异在三点：门槛只锚标准测评与认知课程、金额和游戏进度一律不作业务条件；护栏层硬软分层、硬护栏用确定性代码实现；以及把'不让用户乱买'做成了核心玩法——这是从'促消费的游戏化'到'守合规的游戏化'的方向反转。"

1. 企鹅形象 100% 原创绘制，禁止引用 QQ 宠物、剧本攒等任何现有产品的视觉素材
2. 命名禁用"QQ宠物""小荷包"等既有产品名；对外统一"财富鹅"（正式名）/"鹅豆"（昵称）
3. 剧本文案、话术、日记模板全部原创撰写
4. 对外话术统一为"呼应腾讯系企鹅符号"，不说"把 QQ 宠物搬进银行"
5. 答辩不主动提成长盈；被问时按 10.1 话术应答
