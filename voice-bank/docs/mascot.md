# 财富鹅与业务状态

前端以财富鹅替换原来的球形代表物。素材来自用户提供的“动作精修-透明PNG.zip”（2026-10-29，manifest v8），共 15 项动作、1,596 帧，保留原始 12 FPS 和进入／保持／退出顺序。

正式 768 PNG 经等比缩小到 512，编码成带透明通道的 WebP 图集，没有采用轻量预览包的图片。重复帧去重后为 972 个画面、81 张图集；含清单与静态图约 13.7 MB。每张最多 12 帧、4 列。播放器按需加载，最多保留 4 张解码图集，约 48 MiB；不会预载整个素材包。原始 PNG 不纳入部署包。

| 动作 | 实际触发条件 |
| --- | --- |
| 待机 | 尚未开始、静音或无其他活动 |
| 倾听 | 实时会话已就绪、未静音且处于收音阶段 |
| 思考 | 建立／结束连接、生成回复、核对回复 |
| 使用电脑 | 业务请求正在处理 |
| 讲解 | 语音正在回应 |
| 等待确认 | 后台任务处于 review 或 authenticate；订单结果仍为 pending 等待处理 |
| 成功 | 已完成且有确认记录，或已有转账回执；只读查询不触发 |
| 风险提醒 | 当前任务有后台风险信号 |
| 严肃阻止 | 后台风险校验已拦截当前任务 |
| 失败安抚 | 请求报错、能力未接入或办理受阻 |
| 点赞鼓励 | IN15 理财知识学习返回结果 |
| 成长升级 | IN03 查询到目标储蓄进度达到 100% |
| 投币储蓄 | IN02 存入操作经确认／认证，后台已完成 |
| 护盾守护 | CA06 冻结或 CA07 挂失已完成 |
| 雨天撑伞 | 正在恢复会话并重新核对后台进度 |

动作选择只依赖页面会话状态及后台结构化数据，不解析模型回复中的“成功”等词语。所有结果仍受页面的模拟银行与沙箱范围说明约束。动画不会发起请求、跳过确认或修改业务状态。

连续动作在素材标记的停顿位退出，未完成的进入可沿已经播放的帧返回中性姿态，连续切换保留最新请求。短反馈只播一次；存钱保持段既不倒放也不循环。完成反馈后恢复当前的倾听／讲解／待机状态，同一反馈在当前组件生命周期中不因重渲染重复播放。页面隐藏时暂停，恢复时不会跳帧追赶；减少动态效果模式显示对应动作的静态姿态。加载失败保留最后画面或中性静态图。

实现：`components/wealth-goose.tsx`、`lib/mascot/scenario.ts`、`lib/mascot/sequence.ts`。资源：`public/mascot/`。验证：`npm run check`、`npm test`、`npm run build`；`tests/mascot.test.ts` 包含真实沙箱业务结果映射、单次播放、快速切换、停顿位退出与存钱不倒放检查。
