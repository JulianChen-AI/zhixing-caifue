# 1–20 项快速审核（本地合成夹具）

## 入口与运行

审核页：`/review-lite`。它调用 `lib/workflows/quick-review.ts` 的 20 个确定性合成检查，并用现有 `WorkflowPanel` 展示所选场景的业务卡片。卡片操作直接在浏览器内运行 `reduceBank`；页面不请求 `/api/bank`、实时语音、银行、商户或发卡接口，也不读取持久化会话。

本地启动时使用独立端口，避免和常用的 5173 端口冲突：

```sh
npm run dev -- --port 5180
```

打开 `http://127.0.0.1:5180/review-lite`。不需要 API Key、麦克风权限或真实账户。命令行合成回归为 `npm run verify:lite`（Node.js 22.13+，依赖仓库现有的 TypeScript transform 支持）；运行该命令后按实际终端结果记录，不要把页面或测试文件存在当成运行通过。

## 五分钟验收路径

1. 启动本地开发服务，打开 `/review-lite`。
2. 点击“运行 20 项快速审核”，确认出现 20 行及通过/失败合计；结果以当次运行显示为准，页面不预置通过。
3. 选择第 1 项，核对预期、证据及本地业务卡片；修改目标金额并保存，然后确认。所有变化应显示为本地状态，不发生网络请求。
4. 点击“恢复本项演示数据”，确认卡片回到该项的合成状态；点击“重跑本项”，确认只更新该检查的结果。
5. 选择第 20 项检查校正说明，打开 [竞品矛盾校正说明](competitor-corrections.md)，核对原文 SHA、§3.1/§3.3 与总表行号；不可据此声称竞品当前功能已外部验证。

演示认证如出现在所选卡片中，仅使用固定合成验证码 `123456`；不要输入真实密码或验证码。

## 覆盖范围与限制

- 覆盖：workflow reducer 的合成状态机与适配器；输入、规则、合成流水/产品/账户、状态转移和结果依据。可在所选项上用实际业务卡片手工调整参数、确认或进行演示认证。
- 未覆盖：实时语音/ASR/真人口述、手机麦克风与回声、网络中断、真实银行或商户接口、真实认证、机构正式适当性、生产数据库并发、浏览器持久化，以及本地 UI 的完整端到端回归。
- 第 12 项费用及最坏情形来自内置合成产品数据/边界，不是银行报价、真实产品合同或投资建议。
- 第 13 项工作日估计和第 18 项扣款状态来自合成日历/会话规则；节假日安排、机构到账、外部商户退订及后续扣款均未向外部核验。项目中的“沙箱结算”只改变合成记录。
- 20 项全绿只表示当前合成检查函数按其预期执行，不能升级为真实语音、外部能力或生产金融流程“验收通过”。执行记录见下文及项目审计目录内 VERIFICATION.txt。
