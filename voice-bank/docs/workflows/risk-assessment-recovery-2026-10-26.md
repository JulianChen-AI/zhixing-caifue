# 风险测评逐题保存与任务 Checklist

Issue #2 中的原始“始终停留在产品列表”未在新会话中独立稳定复现；真实 Qwen3.8-Omni-Flash-Realtime 已复现题目顺序与页面不一致、只口头记下逐题答案而未调用工具、三题后口头声称提交但任务仍缺答案。不能据此认定为上下文超限、ASR 或 TTS 故障。

## 修改

- `taskChecklist` 从已持久化的任务参数生成字段表：所需字段、已填值、缺项、可选项、候选值及更新入口。继续使用现有 D1 会话保存，无第二份业务事实或数据库迁移。
- 测评题目和十五个选项由页面与模型共用；三槽答案中 0 仅表示未作答。逐题保存、保留其他题目和来源证据；未答完不进入核对或计算结果。改口使旧确认失效。
- IN05 的 `action:status` 单独查询当前沙箱会话的画像，区分无记录、有效和已过期。查询失败不被转换为无记录；查询不替换未完成问卷。
- 初始提示只保留通用交互与授权规则；具体字段、问卷和下一题由当前任务 Checklist 提供。
- 实时回复结束后比较后台业务事实，不能仅凭 revision 或模型口头承诺认定有进度。无调用、只读状态却未填字段、或未恢复的工具错误，可触发一次 Flash 草稿复核。
- Flash 读取任务字段、近期用户发言、实际调用参数及错误，返回 JSON，由白名单和用户原话校验。它只能提出草稿填写或显示任务；不能确认、认证或直接执行业务。使用现有 `QWEN_PLANNER_MODEL` 配置。失败、超时、歧义保留原进度，不猜答案；插话后丢弃过时复核。
- 测评最终确认保留原生工具结果回传，以便 RealTime 播报结果；不走仅更新页面文字的快捷确认。

## 验证

自动测试覆盖逐题保存与重载、跨业务恢复、选项一致性、否定和歧义拒绝、非法代答和清空、旧确认失效、只读查询、复核的权限边界、失败不改状态、插话后丢弃迟到结果。

真实模型验证采用隔离的合成账户会话：修改后的页面和相同业务 reducer，真实 WebRTC RealTime；Flash 使用服务器已有配置。没有切换现有服务版本，没有进行真人麦克风验收。

可重复执行页面与原生工具回归：

```sh
BANK_TEST_URL=http://127.0.0.1:5180 npm run verify:risk:live
```

需配置真实模型和可用 Chrome、Playwright。默认依次查询产品、查询测评记录、开始问卷、逐题填答、最终确认；脚本断言页面问卷、每次保存的答案、确认前不生成画像以及确认后结果。

`REPRO_AUDIO=1` 使用 macOS Tingting 合成语音走 WebRTC 和 ASR；这是合成语音测试，不等同于真人口音和麦克风测试。`REPRO_NO_TOOLS=1 REPRO_SEED=assessment REPRO_INPUTS='["第一题选三"]'` 故意移除实时模型工具，验证 Flash 自动恢复。测试报告与截图默认写入 `work/`，可通过 `REPRO_REPORT` 指定路径。

## 长对话回归

```sh
BANK_TEST_URL=http://127.0.0.1:5180 REPRO_SCENARIO=long npm run verify:risk:live
```

该场景计划在同一实时连接中执行 44 轮：逐题回答、解释和查询、切换储蓄目标与冻结卡草稿、修改原答案、恢复原任务、确认测评并取消另两份草稿。每轮检查原任务 ID、已存字段、未确认不执行、重复问卷及卡片是否真正恢复；同时记录模型 token 用量、工具参数、调用来源和连接状态。查询未返回对应业务结果时记录 queryFailures，并使最终报告失败，即便测评字段本身未丢失。连接关闭或模型没有完整响应会使测试失败，不能把断线后的本地演示操作计为实时模型通过。遇到业务断言失败即停止，未运行的后续步骤不算覆盖。

2026-10-26 首轮真实模型长测未通过：第 7 轮查询餐饮支出时，RealTime 错选 IN08（购买理财），后台拒绝不支持的参数；Flash 的不符合本轮原话的问卷修改也被证据检查拒绝。第 9 轮开始没有完整实时回复，随后尝试恢复问卷和填写第二题未推进。第一题仍保存为 `[3,0,0]`，未产生测评结果或其他写入。已完成回复报告的最大输入为 12,607 tokens，没有收到上下文超限错误；不能据此认定上下文溢出，也不能将未跑完的 44 轮报告为通过。首轮测试对断线识别不足，后续脚本已加实时连接和完整响应断言，另行重复验证。

第二轮第 10 轮明确失败：用户要求继续原风险测评，RealTime 口头询问第二题但没有调用工具，当前任务和页面仍为 SU01 订阅清单。Flash 复核再次因问卷答案来源校验被拒绝；原问卷及 `[3,0,0]` 保留，连接仍打开，无服务端错误事件。该轮最大输入为 21,955 tokens。第 7 轮还出现将支出查询错派 CA05 的工具链；后台参数检查与调用次数上限限制了错误操作，但未完成用户的查询。这说明任务恢复和跨业务路由仍未稳定，Flash 不能保证纠正实时模型。PR 保留草稿，不将本次提交描述为长流程问题已解决，未部署。
